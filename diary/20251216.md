## Swift の Struct と Type Property, Type Method

- [Animation | Apple Developer Documentation](https://developer.apple.com/documentation/swiftui/animation)
  - struct です
  - ドキュメントでは、「S」のアイコンが冒頭に付いている

- [linear | Apple Developer Documentation](https://developer.apple.com/documentation/swiftui/animation/linear)
  - Animation の Type Property です
  - Animation 型自体に属する「プロパティ」です
  - ドキュメントでは、「P」のアイコンが冒頭に付いている
  - Animation の Type Property にアクセスすると、Animation 型の値が返ってくるのであり、 Type Property は値ではない
    - ちなみに、 Type Property は一つしか存在しない
    - それぞれのインスタンスに存在するのではなく、構造体の型自体に1つだけ存在する

- [linear(duration:) | Apple Developer Documentation](https://developer.apple.com/documentation/swiftui/animation/linear(duration:))
  - Animation の Type Method です
  - Animation 型自体に属するメソッドです
  - ドキュメントでは、「M」のアイコンが冒頭に付いている
